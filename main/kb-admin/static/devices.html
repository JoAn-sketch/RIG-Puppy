设备完整生命周期

这里展示的是物理设备的持久生命周期，不表示当前是否在线；在线、离线、重连属于会话状态，在下方“会话”列展示。

NEW
出厂烧录完成，后端还没有见过这台设备。
→
REGISTERED
后端已识别设备，已有硬件、固件、MAC 等基础记录。
→
UNBOUND
设备存在，但当前没有绑定微信账号，可被用户绑定。
→
BOUND
设备已绑定到微信账号，但画像/配置不一定完整。
→
PROFILE_INITIALIZED
儿童画像和基础配置已创建，等待同步完成。
→
READY
设备完成初始化和配置同步，可正常日常使用。
SUSPENDED
设备被临时停用，例如家长暂停、风控或服务过期；可恢复到 READY。
RESETTING
设备正在恢复出厂，清理 WiFi、Token、本地缓存；完成后回到 UNBOUND。
RETIRED
设备永久退役，不再允许认证，也不能回到 READY。

设备运行状态

这里展示固件的临时本地运行态，只在设备当前执行期间存在，重启后会重新开始。它不代表设备生命周期，也不等同于下方“会话”列的在线/离线状态。

UNKNOWN
尚未完成状态机初始化，或暂时未能从设备读取运行态。
STARTING
固件正在启动，进行基础硬件与系统初始化。
WIFI_CONFIGURING
等待或正在执行 WiFi 配网，尚不能进入正常服务。
ACTIVATING
网络已可用，正在获取凭据、同步配置并完成激活。
UPGRADING
正在下载或安装 OTA/资源升级包；此时不应断电。
IDLE
正常待命，可接收新的互动请求。
CONNECTING
正在建立语音音频通道或重连互动服务。
LISTENING
麦克风与语音处理已开启，正在听孩子说话。
SPEAKING
正在播放机器人回复或系统语音，避免同时采集自身声音。
AUDIO_TESTING
配网阶段的本地音频测试模式，用于验证麦克风与扬声器。
FATAL_ERROR
不可恢复的严重错误；当前状态机不会自动退出，应检查串口和错误日志。
