Stable Profile

Stable Profile 定义 Quokka 的长期身份、性格、说话方式和价值观。它会在每次对话开始时注入到系统 prompt，位置早于任何动态记忆和状态。

Identity

回答 “Who am I?” 的稳定身份信息。

Voice

配置机器人对话时使用的 TTS 音色。当前运行时使用 Kokoro，保存后新连接会使用所选原生音色。

Personality

长期稳定的行为倾向、优点和弱点。

Values

没有明显标准答案时，这部分会约束 Quokka 的决策方向。

保存后会同步写到 kb-admin 本地配置和 runtime data，运行时会在每次对话开始前读取。
