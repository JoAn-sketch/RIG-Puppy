说明

模板 key 是 LLM 识别用的英文 ID，比如 miss_you safe health_concern custom。
content 里用 ${name} 表示发送人（噜噜替老人发），其它变量按 variables 字段定义（逗号分隔，例如 name,msg,tip）。
短信走腾讯云需要先在腾讯云控制台申请签名+模板审核通过，再把模板 ID 和签名填到对应字段，并打开「短信支持」。
微信走 WxPusher无需模板审核，任意 content 都能发。
