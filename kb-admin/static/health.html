自定义字段

外部接口

设备或外部系统可通过 API 上报健康数据，无需认证：

POST /api/health/report
Content-Type: application/json

{
  "field_key": "heart_rate",
  "value": "72",
  "source": "device",
  "note": "小米手环自动上报"
}

// 批量上报
POST /api/health/report-batch
{
  "source": "device",
  "data": [
    {"field_key": "blood_pressure_sys", "value": "125"},
    {"field_key": "blood_pressure_dia", "value": "82"},
    {"field_key": "heart_rate", "value": "72"}
  ]
}
